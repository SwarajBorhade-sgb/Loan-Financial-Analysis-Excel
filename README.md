# 💰 Loan & Financial Analysis – Excel

This project showcases an Excel-based loan repayment model built using **Microsoft Excel financial functions** to analyze loan instalments, principal repayments, interest payments, and total borrowing costs.

---

## 📊 Key Insights Extracted

1. **Loan Amount:** ₹20,00,000
2. **Annual Interest Rate:** 9%
3. **Loan Tenure:** 60 Months (5 Years)
4. **Monthly EMI:** ₹41,516.71
5. **Total Repayment:** ₹24,91,002.63
6. **Total Interest Payable:** ₹4,91,002.63
7. **Principal Repayment** – Calculated using PPMT.
8. **Interest Payment** – Calculated using IPMT.

*All figures are based on the sample loan inputs in the workbook.*

---

## 🧮 Excel Functions Used

- **PMT:** Calculates monthly EMI based on loan amount, interest rate, and tenure.
- **PPMT:** Calculates the principal component of each loan instalment.
- **IPMT:** Calculates the interest component of each loan instalment.

---

## 📌 Tools Used

- **Microsoft Excel**
  - Financial Functions (PMT, PPMT, IPMT)
  - Loan Repayment Calculations
  - Principal and Interest Breakdown
  - Financial Data Analysis

---

## 🧠 Business Application

This model provides an understanding of loan repayment structures, interest obligations, and principal reduction over time. It demonstrates practical financial calculations and Excel-based analysis that can support foundational knowledge of lending and financial operations.

---

## ⚠️ Project Scope

This is an educational financial analysis project. It demonstrates loan amortization and does not represent a credit rating model or an assessment of borrower creditworthiness.
